<p>"原生住宅 IP"是个营销词，不是技术词。它没有统一的判定标准，也没有公开的认证机构，所以不同卖家说的"原生"可能完全不是一件事。与其争论定义，不如把它翻译成七个能测出来的参数：ASN 归属、地址分配年限、历史记录、邻居密度、地理精度、在线率、链路时延。参数摆出来，优势在哪、能值多少钱，就清楚了。</p>
<h2>一、七个参数，一个都别省</h2>
<p>只测其中两三个，很容易得出反向结论。比如一条线 ASN 很漂亮，邻居却密得吓人；另一条线分配年限十年，但晚高峰丢包 5%。单看某一项都会误判，必须七项一起给分。</p>

<h2>二、前三项：ASN、年限、历史</h2>
<h3>ASN 是门槛，不是全部</h3>
<p>org 字段出现 Comcast、Spectrum、NTT、KDDI 这类运营商名，说明这段确实在运营商手里。但要注意，运营商的商用专线段也会挂同样的名字，所以 ASN 只解决"是不是住宅性质"的第一层判断，还要看下面几项。</p>
<h3>年限看 whois，不看宣传</h3>
<p>whois 查到的地址块注册时间，能反映这段资源的稳定程度。注册十年以上的段，通常是长期分配给家庭用户的；刚注册几个月就大量放出来的段，往往是从别处批发来的，稳定性要打折扣。</p>
<h3>历史记录最难查，但最该查</h3>
<p>公开信誉库、段的历史扫描结果、以及同段域名数量，三者结合能看出大致情况。一个段如果过去两年被大量短生命周期域名使用过，即便现在看起来干净，邻居带来的影响仍然存在。</p>
<h2>三、邻居密度与地理精度</h2>
<p>邻居密度是"原生"与否最直接的体现。真实住宅段里，一个 /24 通常只对应几十户家庭，活跃地址有限；被批量转售的段，一个 /24 可能挂着上千个地址。查法是把 IP 段丢进公开的扫描数据里看活跃主机数，或者用 ipwho.is 的 connections 字段辅助判断。</p>

<h3>地理精度为什么重要</h3>
<p>很多 IP 库对同一地址的城市判定并不一致。出口显示在洛杉矶，一个库说是帕萨迪纳，另一个说在内华达，这种偏差会让环境看起来不自然。用三个以上数据源交叉，取一致的结论，再把时区按城市对齐，而不是按国家对齐。</p>
<h2>四、在线率与链路时延</h2>
<p>前五项决定"像不像"，后两项决定"能不能用"。在线率按 7 天窗口统计，每分钟探活一次，成功率 99% 以上算良好；时延按三个时段各测 100 包，看 P95 而不是平均值。</p>

<h2>五、七个参数怎么合成两个结论</h2>
<h3>环境自然度：前五项加权</h3>
<p>把 ASN（30%）、邻居密度（25%）、地理精度（20%）、分配年限（15%）、历史记录（10%）加权，得到一个 0–100 的分数。分数低于 60 的，说明这条线只是在"名义上"是住宅，实际环境并不自然。这个权重是经验值，团队可以按自己的场景调整。</p>
<h3>风控余量：后两项加一致性</h3>
<p>余量不是"能不能过"，而是"还有多少空间"。在线率高、时延稳、且和账号资料一致，余量就大；三者有一项拖后腿，余量就小。余量小的环境，一次异常就可能触发验证；余量大的环境，偶发波动能被吸收掉。</p>

<h2>常见问答</h2>
<h3>原生住宅 IP 有官方认证吗？</h3>
<p>答：没有统一的官方认证。市面上所谓认证多为服务商自建标签，参考价值有限。可靠做法是自己按参数测，并用多个数据源交叉验证。</p>
<h3>城市级定位不一致影响大吗？</h3>
<p>答：有一定影响。定位偏差会导致时区、语言等环境项对不上，让整体显得不自然。建议以多数数据源一致的结果为准，并据此配置环境。</p>
<h3>邻居密度怎么查比较准？</h3>
<p>答：结合段扫描的活跃主机数和 ipwho.is 的 connections 字段，再看同段解析到的域名数量。单看一个来源容易误判，三个一起看参考价值更高。</p>
<h3>自然度分数高就一定能长期用吗？</h3>
<p>答：不能保证。分数反映的是环境质量，账号能否长期使用还取决于资料真实性、使用行为和平台规则。环境只是其中一个维度。</p>
